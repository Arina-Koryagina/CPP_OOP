Три парадигми ООП:
1. інкапсуляція (ховає дані які знаходяться всередині класу)
- модифікатори доступу
private: -- (auto)
public:

2. наслідування ()
3. поліморфізм (багатостановість - здатність об'єктів по-різному реагувати на одній й ті самі виклики)

Обов'язкові функції для класу:
Компілятор робить самостіно (дефолтні функції) за відсутності:
Дефолтний конструктор - виконує початкову ініціалізацію об'єкта
+ при динаміці
Деструктор
Конструктор копіювання
Перевантажений оператор присвоєння

Типи ініціалізації
int a = 5; -- присвоєння
int b(5.5); -- пряма / копіююча
int c{ (int)5.5 }; -- уніформ

Делігуючий конструктор може викликати інші конструктори

explicit забороняє неявну конвертацію (притаманні функціям з одним параметром)
Array b = (Array)10; - явна конвертація
Array b = 10; - неявна конвертація

перевантаження () -- функтор
перевантаження [] -- індексатор
